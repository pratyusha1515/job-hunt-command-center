# Job Hunt Command Center

A full-stack application that helps job seekers save jobs, track applications, manage follow-ups, and understand what is working in their job search.

## Tech Stack

- Frontend: React, TypeScript, Vite
- Backend: Node.js, Express, TypeScript
- Database: PostgreSQL with Prisma

## MVP

- User authentication
- Save and manage jobs
- Track application statuses
- Dashboard with key job-search tasks and statistics

## Project Structure

- `frontend/` — React client
- `backend/` — REST API
